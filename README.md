
El propósito de este trabajo es hacer un entregable final del curso de Introducción a la Ingeniería de Software con Inteligencia Artificial
Es un curso dirigido a estudiantes de la carrera de especialización en inteligencia artificial de la facultad de ingeniería de la universidad de Buenos Aires.

El trabajo final se trata de crear una aplicación con interfaz, servidor y datos que persisten.
Para la presentación hay que definir:
-problema/objetivo: qué resuelve la aplicación
-usuarios: para quien es
-mvp: funcionalidades mínimas que requiere
-stack: con qué se construyen interfaz, servidor y datos

Nuestro grupo va a realizar la app descrita en el file descripcion-app.md
